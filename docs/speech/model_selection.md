# 语音模型选型文档（C-Land 本机部署）

> 硬件：2× Tesla P40 (24GB, Pascal sm_61) + 15GB RAM
> 现状：GPU 0 = SDXL（13GB），GPU 1 = TripoSG（4.15GB 常驻，余 14GB）
> 结论先行：**语音模型全部 ≤0.5B，显存/算力无压力**（可 GPU 1 余量或 CPU），瓶颈在中文质量与许可协议

## 一、需求分类

| 场景 | 模型类型 | 典型用途 |
|---|---|---|
| 角色配音（文本→语音） | TTS | 游戏 NPC、旁白、语音提示 |
| 音色克隆 | TTS + 克隆 | 用 3-5s 样本复刻特定音色 |
| 语音识别（语音→文本） | ASR | 语音指令、字幕、语音聊天转写 |
| 语音理解（情感/事件） | ASR+ | 识别语气、笑声、掌声等副语言信息 |

## 三、决策树

```
需求：游戏/应用语音
├─ 快速原型 / 无 GPU 压力 ─────→ Edge-TTS（零部署）或 Kokoro（本地 82M）
├─ 角色配音（中文，商用项目）──→ Spark-TTS-0.5B（Apache 2.0 最稳）
├─ 角色配音（中文，非商用）───→ CosyVoice2（母语级 + 流式 + 3s 克隆）
├─ 特定音色克隆（5s 样本）────→ GPT-SoVITS（克隆最强，调参费时）
├─ 语音识别（中文+情感）──────→ SenseVoiceSmall（快+全）
└─ 多语言识别 / 转写通用 ─────→ faster-whisper-large-v3
```

## 四、推荐结论

### ✅ 首选组合（游戏中文场景）

| 用途 | 选型 | 理由 |
|---|---|---|
| **TTS 配音** | **Spark-TTS-0.5B** | 中文顶级 + **Apache 2.0 可商用** + 0.5B 轻量 + 流式 |
| **ASR 识别** | **SenseVoiceSmall** | 中文最强 + 情感/事件识别 + 实时率 100 倍 + Apache |
| **音色克隆** | GPT-SoVITS（有需求再上） | 克隆质量天花板，但部署/调参成本高 |

### 备选说明

- **CosyVoice2**：中文质感略胜 Spark-TTS，但 CC-BY-NC 限制商用 → 非商用项目可选
- **Kokoro-82M**：CPU 秒级合成，适合音效/占位/低延迟场景
- **Edge-TTS**：零部署，网络可用即可，适合临时演示
- **ChatTTS / F5-TTS**：各有亮点但维护/速度短板，不优先

## 五、部署规划（确认后执行）

| 项 | 规划 |
|---|---|
| GPU | GPU 1 余量（14GB）或纯 CPU（82M~0.5B 均可） |

| 服务形态 | 常驻 FastAPI（复用现有 server 模式） |
| 输出 | `/mnt/data/ai_workspace/outputs_audio/`（wav/mp3） |
| 显存预算 | 每个 ≤2GB，可同卡共存 |

## 六、风险提示

- **License 红线**：CosyVoice2 模型 CC-BY-NC 不可商用；GPT-SoVITS 克隆他人音色需授权
- P40 无 Tensor Core 对语音模型影响可忽略（模型太小）
- 语音模型多在 ModelScope 分发（阿里系），HF 下载量不代表实际质量，以实测为准
